💼 Employee Payroll Management System
🚀 A Smart MERN-Stack App to Manage Employee Salaries, Attendance & Payslips

Goal: Simplify HR operations by automating payroll calculations, attendance tracking, and payslip generation — all in one secure web platform.

🧩 Overview

The Employee Payroll Management System is a full-stack web application built using the MERN stack (MongoDB, Express, React, Node.js).
It enables organizations to manage employee records, calculate monthly payrolls with tax deductions, and generate professional payslips in PDF format.

🌟 Key Features

✅ Employee Management

Add, edit, and remove employee details with salary structure.

✅ Attendance Tracking

Upload monthly attendance via CSV.

Automatically calculate LOP (Loss of Pay) and payable days.

✅ Smart Payroll Engine

Calculates salary components (Basic, HRA, PF, ESI, PT, TDS).

Generates monthly payroll summaries.

✅ Payslip PDF Generation

Download professional payslips with one click (using Puppeteer).

✅ Authentication & Roles

Secure login with JWT.

Supports multiple roles: Admin, HR, Manager, Employee.

✅ Modern Web UI

Fast React frontend (Vite) with responsive layout and intuitive design.

🛠️ Tech Stack
| Layer          | Technology                           |
| -------------- | ------------------------------------ |
| Frontend       | React.js (Vite), Axios, Tailwind CSS |
| Backend        | Node.js, Express.js                  |
| Database       | MongoDB with Mongoose                |
| Authentication | JWT + bcrypt.js                      |
| PDF Generation | Puppeteer                            |
| File Handling  | Multer + CSV Parser                  |
